四所高校（人族、兽人、矮人、精灵）、一张 16×16 的等距操场、两种指令：**移动**和**攻击**。学生闲下来就会坐下，坐在**营地**上能占领它、加快增援，坐在**泉水**上能回血。把对手的本部坐到沦陷，再把最后一个人击倒，就赢了。

这是一个小时候最爱的游戏。重制版先按原版 SWF 逐函数还原了全部规则，再在不增加系统的前提下，改掉了原版拖沓、不讲理的地方。

## ✨ 特色

- **两套规则，设置里随时切换**
  - **校园战争（默认）**：对局能收尾，战斗更讲理。40 分钟分不出胜负的对局从原版的 57% 降到 1.7%。
  - **经典规则**：逐帧复刻原版，包括原版电脑 AI。
- **不作弊的电脑**：电脑和玩家用同样的规则、同样的指令。分简单、普通、困难三档，四所学校各有性格。
- **四人联机**：建房时选**服务器模式**（对局跑在服务器上，人人延迟相同，谁掉线都不影响别人）或**玩家主机模式**（对局跑在房主浏览器里，其他人直连房主，数据不绕远路）。空座位可放电脑并选难度；掉线 15 秒由电脑代管，回来交还；房主离开会自动换人。
- **四个种族，各有一条特性**：人族占领快、兽人人海、矮人回血快、精灵难被打中。外形、校舍、院子各不相同。
- **顺手的操作**：会绕路的寻路、点哪选哪的选中与发光描边、进攻移动（`A`）、一键撤退回血（`H`）、行进路线、编队、集结点、威胁提醒、悬停说明。
- **全部重新绘制**：角色、校舍、营地帐篷、泉水和校园草木都用代码绘制，音效用 WebAudio 合成。仓库里没有任何原版素材。
- **中文 / English 双语**，带存档读档（3 个手动档位 + 自动存档，可导出、导入）、暂停与倍速、色弱模式。
- **打开就能玩**：纯浏览器运行，没有运行时依赖，打包后约 146 KB（gzip 后 50 KB）。联机另需一个小的 Node 服务（房间、信令、中转，服务器模式下也跑对局）。

## 🎮 怎么玩

| | 规则 |
|---|---|
| **营地**（帐篷） | 坐在上面占领它。占的营地越多，增援越快 |
| **泉水**（石泉） | 坐在己方的泉水上回血。也可以占领 |
| **本部** | 每所学校的大本营：出兵、回血。敌人在你的本部上坐满约 33 秒·人，本部**沦陷**：停止增援、不能回血。派人坐回去约 17 秒·人就能夺回 |
| **出局** | 本部沦陷，并且一个学生都不剩 |
| **击倒成长** | 每击倒一人：回血 30%、生命上限 +2，脚下升起光柱；每击倒 3 人头顶落下一颗星，成为老兵 |
| **众矢之的** | 势力超过全场 40% 的学校会成为其他电脑优先攻击的对象（只剩两所学校时取消） |

出拳命中率是 50%，挥空时会冒出"闪"字。被打中会打断出拳，所以围殴很强，这是原版最有味道的地方，重制版完整保留了。

### 操作

| 操作 | 按键 |
|---|---|
| 选中 | 左键点击或拖框 · `Shift` + 点击加选 / 减选，`Shift` + 拖框追加 · 双击学生选中屏幕内全部己方学生 · `Ctrl` + `A` 全选 |
| 移动 / 攻击 | 右键地面 / 右键敌人 |
| 进攻移动 | `A`，再点地面：边走边打 6 格内的敌人，打完继续前进 |
| 撤退回血 | `H`：选中的人走向最近的己方泉水或本部；没选人时撤回全部伤员 · `Shift` + `H` 选中全部伤员 |
| 编队 | `Ctrl` 或 `Shift` + 数字编队 · 数字键选队 · 连按两次镜头跳过去 |
| 集结点 | 点自己的校舍，再右键地面，新兵会自动前往 · 右键本部取消 |
| 视野 | `空格` + 拖动 · `WASD` / 方向键 · 点小地图 · 滚轮缩放 |
| 暂停 / 倍速 | 右上角按钮 |

### 四所高校

| 高校 | 特点 | 特性 | 生命 | 攻击 | 增援 |
|---|---|---|---|---|---|
| 🔵 人族高校 | 均衡、扩张 | **团结**：占领快 30% | 17（原版 20） | 4 | 慢 |
| 🟢 兽人高校 | 人海 | **人海**：增援极快 | 12（原版 10） | 4（原版 2） | 极快 |
| 🟡 矮人高校 | 坚韧 | **皮实**：回血快一倍 | 28（原版 25） | 3 | 慢 |
| 🟣 精灵高校 | 强攻 | **灵巧**：被命中率 42%（其他人 50%） | 12（原版 15） | 5 | 慢 |

四个种族分别由原版的黑曜、绿林、金刚、紫电四所学校改造而来。括号里是经典规则下的原版数值；经典规则也用新的种族外观，但没有特性。新规则的数值是用上千局无头模拟调出来的，原版中绿林（兽人）在电脑互打时胜率为 0%。

## 🔧 和原版相比改了什么

每一条改动都能用一句话讲清楚，并且用无头模拟验收过：

- **让对局能收尾**：本部可以被攻陷；增援在人满时攒着，不再白白浪费；没人继续占领的地块，进度会慢慢回退；"众矢之的"只剩两家时取消，而且不再保护本部已沦陷的学校。
- **战斗更讲理**：闲着的学生优先迎战最近、正在打自己人的敌人，而不是随机挑一个；走动中的单位也能被打中；执行移动指令时不会被敌人拉走；自动追击最远 12 格；倒地的学生立即让出格子。
- **好操作**：寻路改成 A*，被人挡住会绕过去，目标格有人就停在旁边；加入进攻移动和撤退回血两个快捷操作。
- **看得懂**：势力比例条、占领进度环、增援倒计时、挥空提示、受击闪白、升级光柱与老兵光环、选中描边、悬停说明。

完整的设计、数据和取舍见 [docs/03_优化方案.md](docs/03_优化方案.md) 与 [docs/04_体验升级方案.md](docs/04_体验升级方案.md)。

## 🤖 电脑 AI 实测

所有数据都来自可复现的无头模拟（`npm run sim`，40 分钟为上限）：

| 对局 | 结果 |
|---|---|
| 普通 × 4 混战（300 局） | 人族 / 兽人 / 矮人 / 精灵胜率 24 / 23 / 27 / 25%，中位时长 13 分钟，1.7% 未分胜负 |
| 困难 × 4 混战（300 局） | 29 / 34 / 27 / 11%，精灵偏弱 |
| 困难 vs 原版 AI（180 局） | 困难方赢 94.3% |
| 普通 vs 原版 AI（180 局） | 普通方赢 84.2% |
| 困难 vs 普通（180 局） | 困难方赢 89.9% |

指挥官每隔一段时间评估一次局势，把学生分配到撤退、防守、扩张、进攻四类任务。它只能下达和玩家一样的指令，不读取任何玩家看不到的信息，也没有属性加成。三档难度的差别只在反应速度、协同程度和是否集火。

## 🌐 联机

标题画面点"联机对战"，填名字、选模式和规则后建房，把邀请链接（`?room=房间号`）发给朋友。大厅里会显示每个人到服务器的延迟、每两人之间能否直连及其延迟，并按测得的数据建议用哪种模式。

| | 服务器模式 | 玩家主机模式 |
|---|---|---|
| 对局在哪里跑 | 服务器 | 房主的浏览器 |
| 延迟 | 每人到服务器的往返延迟，人人一样 | 到房主的直连延迟，同城、同国通常低得多；房主几乎零延迟 |
| 直连不上的人 | — | 自动经服务器中转（延迟约为两人到服务器的延迟之和） |
| 掉线、离开 | 不影响别人；15 秒后电脑代管 | 同左；房主断开 4 秒后换人，对局暂停几秒 |

两种模式都只传指令，自己的操作在本机下一帧就生效，不用等网络往返。联机局没有暂停、倍速和存档。设计、取舍、实测数据和仍有的限制见 [docs/05_联机方案.md](docs/05_联机方案.md)。

## 🚀 本地运行

需要 [Node.js](https://nodejs.org/) **22.18** 或更高版本（命令行工具直接运行 `.ts` 文件）。

```bash
git clone https://github.com/mituan-ai/school-wars.git
cd school-wars
npm install
npm run dev          # 开发服务器，浏览器打开显示的地址
npm run server       # 另开一个终端：联机服务（127.0.0.1:8787，开发服务器会把 /net 转给它）
```

| 命令 | 作用 |
|---|---|
| `npm run build` | 类型检查 + 生产构建：网页到 `dist/`（纯静态文件），联机服务到 `dist-server/server.mjs`（`node dist-server/server.mjs` 运行，由 Web 服务器把 `/net` 的 WebSocket 反代过去） |
| `npm test` | 90 项规则、寻路、AI、模拟与联机测试 |
| `NET_DELAY=110 npm run server` | 联机服务每个方向加 110 ms 延迟，本机模拟往返 220 ms；网址加 `?relay=1` 强制不直连 |
| `npm run sim -- 300 40 --rules remake --ai normal` | 无头跑观战局：局数、最长分钟、规则、难度 |
| `npm run sim -- 100 40 --rules remake --vs hard,classic` | 两种 AI 各控制两所学校，统计胜者 |
| `node tools/balance.ts 160 '17,12,28,12' '4,4,3,5' '1500,500,1500,1500' normal` | 阵营数值扫参（后面还可以跟占领、回血、被命中三项特性） |

## 🏗️ 技术架构

- **TypeScript（strict）+ Vite + Canvas 2D**，界面用原生 DOM，没有框架，也没有运行时依赖。
- **确定性的纯逻辑核心**：`src/core/` 不依赖浏览器，固定 18 tick/s，随机数带种子并保存在状态里。同样的种子和指令一定得到同样的对局，存档就是状态本身的 JSON。
- **原版对照**：经典规则下，核心逐函数对应原版 ActionScript（文件头标注了出处帧）。改动前后各跑 20 局 × 6000 帧，事件流指纹完全一致。
- **测试驱动平衡**：测试里内置了小型锦标赛门槛，例如困难 AI 对原版 AI 胜率要超过 75%，普通混战的僵局不超过 10%。调 AI 或数值时测试会把关。

```
src/core/          纯逻辑，可在 Node 中无头运行
  mapgen.ts        地图生成与开局
  spawn.ts         增援
  unit.ts          单位状态机、战斗、占领
  path.ts          A* 寻路（仅新规则）
  ai-classic.ts    原版电脑 AI
  ai-commander.ts  新电脑指挥官
  sim.ts           主循环与指令
  save.ts          存档（v3，自动迁移旧版）
src/net/           联机：协议、权威、客户端预测、链路、WebRTC、浏览器端会话
server/            联机服务：房间、信令、中转、服务器模式的权威
src/render/        等距地图、校园景物、矢量角色、小地图、特效
src/ui/            标题、对局界面、联机大厅、菜单、存读档与设置
src/i18n/          中文 / English
src/audio/         WebAudio 合成音效
tests/             Vitest 测试；e2e/ 为浏览器冒烟脚本
tools/             观战统计、数值扫参
```
