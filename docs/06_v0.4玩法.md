# 校园战争 v0.4：地盘、成长与像素风

> 目标：原版的玩法只有"坐营地"一种经营手段，坐下来除了增援快一点没有别的意义，打到中盘就只剩拉锯。v0.4 给"占地方"和"打赢"都加上看得见的回报，并让局面有起伏；同时整体换成像素风。
> 约束：新玩法只进"校园战争"规则，**经典规则仍逐帧复刻原版**（117 个测试里的原版回归全部通过）。所有规则都在 `src/core/` 里，是确定性的，联机、存档、电脑都用同一套。

## 1. 地盘与补给线（`src/core/territory.ts`）

参考《三国志 14》的填色占领：

- **涂地**：学生站在空白大格上，`PAINT_NEED` = 18 帧（1 秒）后这一格归他的学校；同一格最多算 3 人（`PAINT_CREW`），敌方已经涂过的格子要 3 倍时间（`PAINT_ENEMY_MUL`）。营地、泉水、本部仍按原来的"坐下占领"。
- **补给**：从未沦陷的本部出发、经由己方格子**四向连通**的地盘才有补给。只有连上补给的营地加快增援、泉水回血、坐着加经验。切断对手的补给线不用打下营地，涂穿中间一格就行。
- 补给每帧只按这一帧开始时的地盘算一次，同一帧里先后发生的占领不会让结果依赖执行顺序（联机一致性需要）。
- 画面：各校颜色铺满自己的格子，交界处描深色边；断了补给的地盘画成斜纹；正在涂的格子从中心向外长出颜色。悬停空白格会显示归属、是否断补给、涂色进度。

## 2. 基地经验与升级（`src/core/growth.ts`）

| 来源 | 经验 |
|---|---|
| 坐在**连着补给**的己方营地上 | 每人每帧 +1（每秒 18） |
| 有补给的空白地盘 | 每秒 +地盘格数 / 2（2 格起算） |
| 击倒一个敌人 | +60 |
| 下课铃小卖部（§5） | 每人每帧 +2，最多算 3 人 |

第 n 次升级（n 从 0 起）要 2400 + 1200·n 经验。攒满一次，左下角的面板就能挑一项：

| 升级 | 每级 | 最多 |
|---|---|---|
| 生命 | +15%（按种族基础值取整） | 3 级 |
| 攻击 | +1 | 3 级 |
| 移速 | +1/6 | 3 级 |
| 增援 | 出兵间隔 −15% | 3 级 |

升级**只影响之后新出的学生**，场上的人不变，所以不会一次升级就翻盘。电脑当场按各校偏好自动挑（人族先攻击、兽人先增援、矮人先生命、精灵先攻击再移速）；玩家用 `upgrade` 指令挑，联机时和其他指令一样经权威定帧。

## 3. 班长与小队（`src/core/squad.ts`）

- 满三星（击倒 9 人）的学生成为**班长**，头上有皇冠。
- 班长身边 4 格内的己方学生（含班长自己）出手更准：命中率 ×1.2。
- 班长会从身边 8 格内闲着、血量六成以上、没在占领或回血的己方学生里招**最多 3 人**组成小队（队员头上有小箭头）。
- 玩家派班长去哪，队员跟到哪；班长闲着时带队去打 16 格内看得见的敌人或敌方地盘。
- 玩家单独给某个队员下令（不带班长），这名队员就离队。班长倒下，小队解散。

## 4. 夹击（`src/core/unit.ts` `flankSides`）

一个学生同时被**两个方向**相邻的敌人打，敌人的命中率 ×1.3；三个及以上方向 ×1.5。倍率乘在种族的被命中率上，所以精灵"难被打中"的相对优势不会被抵消。夹击成立时目标头上飘橙色的"夹击！"。

## 5. 下课铃（`src/core/bell.ts`）

- 开局 90 秒第一次响，之后每 120 秒一次。
- 铃响时在地图中部 8×8 范围里挑一个空白格（四邻不能是营地 / 泉水）开成"小卖部"，开 40 秒。
- 开着时，只有**一所学校**的人站在上面，这所学校就按人数加经验；两校同时在上面谁也不加。
- 右上角显示下次铃响的倒计时，点一下镜头跳过去。电脑会把小卖部当成一个临时地块去争。

## 6. 战争迷雾（`src/core/fog.ts`、`src/render/fogview.ts`）

- **视野**：学生看得见周围 7 小格，本部 9 小格，己方地盘（营地、泉水、涂过的格子）看得见自己和外面一圈。都是切比雪夫距离。
- **重新起雾**：看过的地方 20 秒内是"记忆"（半透明，地盘颜色停在最后看见的样子，看不到人）；超过 20 秒变回全黑。
- 各校本部的位置和归属人人都知道。
- 设置里可以关（"战争迷雾（校园战争规则）"，默认开）；联机房间由房主在大厅里勾选。观战、出局后什么都看得见。
- **电脑**：只知道看得见的敌人在哪。兵力对比仍按全局估算（当作情报），营地归属也按实际。这是有意的简化，见 §9。
- 迷雾只是画面上的记忆，不进存档、不进状态指纹。

## 7. 像素风（`src/render/`）

做法是"低分辨率画布 + 整数放大"，在保留任意缩放的前提下得到硬边像素：

1. 整个世界画在一张**美术画布**上，1 美术像素 = 2 世界单位（`ART = 0.5`）。
2. 先按整数倍 k = ⌊缩放 × dpr / ART⌋ 最近邻放大，再用双线性缩放到准确尺寸（只差不到一倍，几乎看不出模糊），加上亚像素偏移，镜头平移不抖。
3. **学生**（`pixel-student.ts`）：沿用原来的骨骼姿势，在像素网格上逐块画身体，头部是每个种族手绘的正面 / 背面像素图；左右方向镜像；倾斜小的用行错位，躺倒等大角度用最近邻旋转。
4. **帐篷、泉水、校舍**（`props.ts`）：矢量图形烘焙成像素精灵：透明度阈值切硬边 → 颜色收拢到十几种 → 1 像素描边（`pixel.ts` `pixelate`）。图标（星、皇冠、铃等）直接是像素图。
5. **背景**（`backdrop.ts`）：草地、地砖、路沿、树木只烘焙一次。
6. **地面层**（`ground.ts`）：地盘填色、交界描边、断补给斜纹、涂色进度、迷雾（边缘按棋盘格抖动）逐像素算在一张 768×384 的画布上，每帧最多重算一次。中盘实测帧间隔稳定 16.7 ms。
7. **文字**：画面里的字先用像素字体按 12 像素原生字号写好、切掉半透明边、加描边再贴上去；界面只用 12 / 24 / 36 / 72 像素四个字号，关掉字体合成粗体，按钮、面板都是平涂加 2 像素硬边框，没有圆角和阴影。

### 字体

[缝合像素字体 Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font)（12 像素，简体中文，SIL Open Font License 1.1）。只保留游戏里用到的 1119 个字，woff2 约 40 KB：`public/fonts/fusion-pixel-12.woff2`，许可证在同目录 `OFL-fusion-pixel.txt`。改了界面文字后用 `tools/subset-font.py` 重新裁剪（需要 `fonttools` 和 `brotli`）。

## 8. 数值调整

加入地盘和经验后，兽人人海太弱、精灵太强 / 太弱的问题重新出现，按模拟结果调了两处：

| | v0.3 | v0.4 |
|---|---|---|
| 兽人增援间隔 | 500 | 750（仍是其他学校的两倍快） |
| 精灵被命中率 | 42% | 38% |

## 9. 实测（`npm run sim`，40 分钟为上限）

除"普通 × 4（无迷雾）"一行外都开着迷雾（`--fog`）。

| 对局 | 结果 | v0.3 对照 |
|---|---|---|
| 普通 × 4 混战（300 局） | 人族 / 兽人 / 矮人 / 精灵胜率 23 / 27 / 23 / 25%，中位时长 10.0 分钟，1.7% 未分胜负 | 24 / 23 / 27 / 25%，13 分钟，1.7% |
| 普通 × 4 混战，无迷雾（300 局） | 23 / 27 / 21 / 27%，中位 9.8 分钟，2.3% 未分胜负 | — |
| 困难 × 4 混战（300 局） | 26 / 26 / 33 / 14%，中位 9.2 分钟，1.3% 未分胜负 | 29 / 34 / 27 / 11% |
| 困难 vs 原版 AI（180 局） | 困难方赢 98.9% | 94.3% |
| 普通 vs 原版 AI（180 局） | 普通方赢 88.0% | 84.2% |
| 困难 vs 普通（180 局） | 困难方赢 87.8% | 89.9% |

对局变短了约 3 分钟（中位 13 → 10 分钟）：经验升级让领先的一方滚得更快。普通难度四族基本平衡；困难难度精灵仍然偏弱（14%），和 v0.3 一样，留待后续。迷雾对胜率分布影响很小。

## 10. 已知限制

- 电脑在迷雾里仍然知道各校总兵力和营地归属，只有敌人的具体位置受迷雾限制。
- 电脑很少组成小队：它的学生大多被指挥官分配了任务，小队只从没任务的闲人里招。
- 没选中人时按 `H` 仍然按"血量低于一半"挑重伤员撤退。
- 联机的"战争迷雾"房间选项需要重新部署服务器（`server/hub.ts`）才生效；旧服务器上建的房间迷雾默认关。
- 迷雾只挡画面，网络上收到的仍是完整状态，懂行的人能从浏览器里读出来。指令同步的架构下这一点无法避免。
